# FreeCAD 工程仓库总览

本仓库是 `2395300049-sys` 账号下 FreeCAD 工程工作流的索引与迁移记录。它不存放具体客户图纸、CAD 模型、报价或任务输出，只说明各版本的定位、关系和验证边界。

## 仓库清单

| 仓库 | 定位 | 相比前版的关键推进 | 规模 |
|---|---|---|---:|
| [`v2`](https://github.com/2395300049-sys/v2) | 二维图纸到可验证 FreeCAD 零件、装配体和 A3 工程图 | 参考 STEP 校准、坐标系统一、物理实例去重、异机重建 | 2 个 Python 脚本，4 份参考文档 |

## 演进关系

```text
V2 可靠建模与装配
 └─ V3 版本化、可追踪交付
     └─ V4 干涉审计与修复回归
         └─ V5 生产工程全流程
             └─ V8 证据控制、纠错修复与分级发布
```

V6 和 V7 没有在源账号中以独立仓库出现；其工作流路由、制图质量、GUI/视口、实例台账和 STEP 往返验证内容已作为参考资料合并进 V8。

## 选择建议

- 新项目优先使用 V8。
- 只需把图纸稳定重建为零件和装配体时，可参考 V2。
- 对交付目录、原始图纸留存和 STEP 完整性要求高时，重点参考 V3。
- 遇到齿轮、轴、轴承座或壳体碰撞时，使用 V4 的干涉审计方法。
- 涉及方案、载荷、制造、公差、成本或供应链时，使用 V5/V8 的生产工程门槛。

## 验证边界

- 脚本执行成功不等于几何、装配、工程图或生产发布全部合格。
- STEP、FCStd、PDF、GUI 视口和异机重建是不同验收门，需要分别核对。
- “几何可评审”“工程可评审”“可投产发布”必须分级报告。
- 公开仓库不自动获得开源许可；本次整理未添加许可证。
- 仓库仅包含可复用 Skill、脚本、参考资料、模板和元数据，不应包含客户原图、真实 CAD 交付、凭据或机器缓存。
